#Proyecto final de último año de la materia Desarrollo de Aplicaciones Móviles y Bases de Datos (año 2026), hecha por Andromeda Team (Steven/Nazareth/Josué/Sebastián).

#Esta aplicación consiste en un divisor de montos, cual el usuario ingresa a las personas y los diferentes montos. La app se encarga de dividir los montos entre las personas agregadas, y permite editar si una persona lleva mayor o menor carga monetaria.

#La aplicación fue programada en el lenguaje Flutter/Dart para que fuera compatible con las plataformas Android e iOS al mismo tiempo con el mismo código.

#La finalidad de la aplicación es resolver los problemas monetarios generados al hacer trabajo en grupos o juntarse con amigos, de quien paga esto, o si alguien no puede pagar tanto, dividiendo los montos, con posibilidad de reajustar los montos en base a la carga monetaria que el usuario crea razonable.
